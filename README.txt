ARUNA VIP DEMO
================
Premium luxury villa booking platform demo.

Run:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. No build step is required.

Included:
- Premium homepage
- Villa listing + filters
- Villa detail + dynamic-looking booking card
- 3-step booking demo
- Booking confirmation
- AI concierge simulated interaction
- Experiences
- Guest account
- Full admin dashboard with bookings, villas, calendar, customers, revenue and settings
- Responsive mobile layout
- Generated showcase imagery

This is a front-end demo. Payment, authentication, email, WhatsApp, and database integrations are simulated and can be connected later.
